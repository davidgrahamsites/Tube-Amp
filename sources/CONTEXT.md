# Source evidence

One job: retain traceable evidence extracted from original project inputs.

## Inputs
Original user files in the project root and their recorded hashes.

## Process
Preserve originals. Store extracted evidence in a source-specific folder with mapping and hashes; distinguish source content from engineering interpretations.

## Outputs
Reviewable source images, manifests and inspection records. Canonical requirements remain in the handoff and decisions in the brain.

## Human check
Compare a disputed transcription against its source image before using it in the circuit or purchasing list.
