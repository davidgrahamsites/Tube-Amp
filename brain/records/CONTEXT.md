# Engineering records
One job: retain project-specific decisions and evidence.

## Inputs
[Templates](../_templates/CONTEXT.md), [sources](../sources.md), [rules](../rules/CONTEXT.md), and affected project files.

## Process
Copy a matching template; use a stable ID and descriptive filename. Capture alternatives, evidence, open questions and next checks. Update status as evidence changes; link replacements when superseding decisions.

## Outputs
Editable decision, component and validation Markdown files, cataloged in [INDEX.md](../INDEX.md).

## Human check
Review evidence, reasoning, exact affected revision and unresolved choices before relying on the record.
