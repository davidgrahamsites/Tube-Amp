# tools contract

Owner: Renegade integration agent. One job: retain the imported starter tools and its original evidence.

## Inputs
Paths in this contract are project-root-relative unless named as local. Read `Renegade_KiCad_Library_Starter.zip` and `brain/records/VAL-001-starter-archive-match.md`. Local edit/evidence surfaces include `verify_bundle.py`.

## Process
Imported reference. Original supplied files remain byte-preserved; this contract is an added ICM navigation overlay. Keep source inputs, stable scripts and run products identifiable by their registered roles. This contract adds navigation in place; it does not rerun, relocate or approve the existing design. New active runs belong in a revision module with separate tools, evidence and products.

## Outputs
The local files listed above and their children remain the module outputs. `brain/catalog/FILES.json` indexes their roles and hashes; `brain/materials/register.json` identifies the owning material route.

## Human check
Open the local output with its source/reference and confirm revision, unresolved limits and actual part or circuit identity before using it for the build. For native CAD, inspect the render and pin/geometry checks; for runs, inspect assumptions and logs.
