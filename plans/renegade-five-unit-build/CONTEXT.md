# Five-unit combo amplifier planning run

One job: define an economical, delegable Shanghai combo-amplifier build.

## Inputs
User discussion, ../../Renegade_Codex_Handoff.md, ../../PROJECT_STATUS.md, and ../../brain/CONTEXT.md.

## Process
Run the requested five-times-skill-plus method: draft, fresh critique, targeted research, fresh pre-mortem, fresh final review. Keep each version file plan-only. Separate research and implementation/evidence records from plan versions.

## Outputs
v1.md, v2.md, v3.md, v4.md and final.md. Only final.md is the current executable handoff after all reviews complete.

## Human check
Review product choices, budget confidence, exact supplier quote conditions and release dependencies. Planning does not itself release circuit hardware for construction.
