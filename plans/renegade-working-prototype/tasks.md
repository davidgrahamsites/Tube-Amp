## Execution contract

One numbered task is active at a time. Complete its evidence and update this queue before advancing. If a task needs an unavailable measurement, record the exact blocked dependency and advance to the earliest independent task; never count a provisional result as a pass. Work within each functional block and its declared interfaces. An engineering change that alters another block's interface reopens the affected earlier checks.

Existing decisions stay fixed: selectable 120 V / 220 V electric build (FB-106; prior deferral superseded), four 12AX7 plus two EL34 tubes, delivered cabinet and tank, original tube input without added buffer, separate audio/power/reverb physical-board direction with control functions retained, PCB-side connectors and insulated wiring, independently removable rear wood, accessible mounting screws. Tube visibility is desirable only if function, insulation, heat and service access allow it. No purchase or manufacturing release is implied.

Effort below describes scope, not a promised elapsed time: S = bounded audit/repair; M = several linked checks; L = substantial design iteration; H = requires physical work. Each row names its inputs, output, dependencies and objective completion evidence. Exact execution revisions and commands belong in the linked module's evidence, not duplicated here.
