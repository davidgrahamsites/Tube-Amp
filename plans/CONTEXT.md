# Project planning records

One job: preserve reviewable project plans.

## Inputs
User requirements, the canonical project handoff, current project status, and relevant brain rules/evidence.

## Process
Each planning run has a dedicated topic folder. Preserve plan versions separately from critiques and research. Follow the requested review method; keep reviewer prompts free of prior-review history.

## Outputs
Versioned Markdown plans and a runnable final plan in each topic folder.

## Human check
Read the final scope, assumptions, milestones, cost confidence and unresolved decisions before committing spending or production.
