# Heater-elevation divider rating
Owner: component selection. One job: qualify bounded resistor voltage/power and compare correction candidates at the existing HREF interface.
Inputs: contract.json, current R506/R507/C505 source and selection identities, manufacturer FMP/PR documents. Current source hash and native baseline are guarded.
Process: tools/screen.py enumerates normal and declared single-fault DC corners and independently compares RC startup with ngspice. Candidate screening does not mutate source or PCB.
Outputs: results/screen.json, simulator log, review.md and supplier observations. Selection, CAD adoption and actual transformer/thermal qualification are separate gates.
Human check: inspect source pin map, correct resistor wire variant, hot placement, film/lead temperatures and physical lead forming. R507-open and R506-short hazards are not fixed by a higher-rated R506.
Task HD-001: baseline78919a2; estimated one scoped engineering wave; done when bounds, alternatives and preserved native inputs are recorded. Exact domestic supply and populated thermal evidence remain required for adoption/release.

Task HD-002: baseline d5566cd; one diagnostic wave. interface-contract.json binds current cathode/heater topology, existing fixture/models and primary tube-reference limits. tools/interface_screen.py samples cathode extremes; tools/check_interface.py independently audits interval intersections and receipts. Results and interface-review.md establish whether resistor selection alone can qualify the existing shared reference. Done means source-bound findings and a correction boundary, not a redesigned heater supply or a qualified tube. Exact tube identity, actual supply, startup and physical verification remain required.

Task HD-003: correction-contract.json owns the split-reference/bounded-supply comparison. tools/correction.py writes current normal/fault/audio evidence; tools/check_correction.py independently checks arithmetic, source cathode paths and preserved native hashes. correction-review.html is the human report; results/correction-100k-rejected.json retains the rejected trial. Done means source-bound correction evidence, not a guaranteed 300 V supply or native adoption. Next: implement the ceiling and fault response before dependent routing.

Task HD-004: supply-contract.json binds the coupled R17 load and candidate regulator boundary. tools/supply.py writes DC/audio evidence; tools/check_supply.py checks independent current balance, cold-divider voltage, saved-waveform power and input isolation. supply-review.html is the human report. results/supply-confounded-rejected.json retains the rejected shared-screen experiment. Real limiting/protection and exact parts remain required before native adoption.

Task HD-005: ceiling-contract.json owns the680ohm feed candidate and declared570–805ohm allocation. tools/ceiling.py reuses the HD-004 adapter through config/DC/worker calls; tools/check_ceiling.py independently reconstructs resistance bounds, nodal heat and saved-waveform results. ceiling-review.html is the human report; results/ceiling-initial-tolerance.json is the compact superseded trial. No transistor, fault interruption or native adoption is implied. Human check: confirm exact resistor variant, temperature allocation and independent fault response.

Task HD-006: baseline ecc2c71; one bounded model/application wave. pass-contract.json binds original model, topology, inputs and limitations. tools/pass_topology.py owns generated translation fixtures and candidate runs; tools/check_pass.py independently checks current balance, fault applicability, waveform receipts and native preservation. pass-review.html is the human report. Done means reproducible study evidence, not adopted protection. Human check: validate real fault interruption, reverse behavior, supported dynamic model, hot operation and exact parts before native adoption.

Task HD-007: baseline2578e1f; one bounded series-pass correction wave. series-contract.json binds HD-006 adapter, topology and single-pass-short scope. tools/series_protection.py writes DC cases, solver controls and a regulator-short probe; tools/check_series.py independently checks current balance, limits and native hashes. series-review.html owns findings. Done means a reproducible conditional correction, not complete protection. Human check: require an independent absolute output limit, supported dynamic/hot evidence and exact parts before adoption.

Task HD-008: baseline d710958; one forced-control and detector-window wave. absolute-contract.json binds the prior adapters, allocated sensitivities and control-port requirements. tools/absolute_authority.py writes forced-on DC cases; tools/check_absolute.py independently checks current balance, coverage, limits and native hashes. absolute-review.html owns the choice and calculations. Done means an actuator comparison and a necessary detector-window check, not automatic protection. Human check: qualify exact detector, drive, hot authority, delay/overshoot and reverse behavior before adoption.

Task HD-009: baseline222ccd7; one detector/setpoint integration wave. detector-contract.json owns part evidence, error allocations and the42.2k programming candidate. tools/detector_candidate.py produces threshold endpoints, coupled static control, floating-model fixtures and guitar-input AC comparisons; tools/check_detector.py independently checks bounds, KCL, coverage, audio dependencies and native hashes. detector-review.html owns the decision and limits. Done means a conditional static candidate, not a fault latch or protection release. Human check: actual monitor supply, hot actuator, response time, reverse behavior, exact parts/socket carriers and populated fit remain required.
