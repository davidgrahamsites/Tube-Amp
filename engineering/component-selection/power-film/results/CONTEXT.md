# Package comparison results
`assembly-options.json` is regenerated by `../tools/assembly_options.py`. It records candidate input hashes and explicit exclusions; human check: do not mistake a four-body envelope for a finished board or chassis fit.

Owner: component selection. Inputs: parent contracts and native board, identified by hashes. Process: regenerated by `../tools/check_packages.py`; no hand-edited numerical results. Output: package-checks.json. Human check: trace reported pad spacing to the board and manufacturer drawing and review unresolved insertion, thermal and procurement gates.
