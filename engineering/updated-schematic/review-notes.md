## Presentation revision v0.3 - October 4, 2026

The user requested familiar wired drawings instead of a global label at each pin. Manual positions now arrange audio stages left to right and group power/control circuits by function. Continuous wires, explicit junctions and standard ground symbols replace intra-sheet pin labels; 71 labels remain at sheet interfaces. The PDF uses wire hops at crossings. Native Value fields remain identical to v0.2; compact visible Display fields shorten long descriptions. Exact exported pin partitions also match v0.2. The first redraw failed native parsing (quoted pin-type keyword /missing page-string quoting), then the native comparison caught rotation and redundant wire-tail issues; all were corrected before delivery. Current export and full ERC succeed with the original one ground/earth alias warning. This is a presentation change and does not advance build qualification.
