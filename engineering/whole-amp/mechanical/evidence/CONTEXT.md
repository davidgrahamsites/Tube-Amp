# Dimensional source evidence
Owner: integration agent. One job: preserve received/downloaded source bytes.
## Inputs
User cabinet views, prior manufacturer cabinet images, public Mable listings and Accutronics reference sheet.
## Process
Keep sources unmodified; record URLs/date and model applicability in `../review/fit-review.md` and `../review/tank-specifications.md`.
## Outputs
Read-only source files consumed by `../fit-register.json`; old register retained for history.
## Human check
Match the photographed or delivered product label to the exact source before using its dimensions.
