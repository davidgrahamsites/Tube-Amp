# PCB measured-R integration tools
Owner: Renegade PCB integration. One job: Reconcile existing boards without modifying historical originals.
Inputs: ../pcb historical native boards, ../reverb-600/circuit.json and ../../component-selection coverage/footprints (paths relative to module root).
Process: use the ordered operation list in ../CONTEXT.md. Creation, placement refinement, routing, DRC correction and read-only audit are separate scripts. Creation refuses overwriting existing drafts; refinement removes Reverb routing and must not be rerun over later edits. Execute with KiCad bundled Python. Native CLI DRC remains authoritative for copper connectivity and spacing.
Outputs: boards/*.kicad_pcb and review/integration.json plus native DRC reports. All are drafts; no fabrication package.
Human check: inspect pads, courtyards, remaining routing, full six-tube assembly and delivered-cabinet clearance. Expression pedal is still pending.

export_mechanical_inventory.py is a read-only KiCad adapter. It exports exact rectangular board extents and nominal round NPTH mounting geometry with board hashes and missing3D-model references to ../review/mechanical-inventory.json. Unsupported mounting shapes fail explicitly. Mechanical placement and fit conclusions belong to ../../mechanical, not this adapter.

check_fc6136_fit.py reads the component-selection FC6136 fit contract and native Power board, rejects impossible straight-lead row pitches and screens centered maximum-body overlap. Output: ../review/fc6136-fit.json. It never edits CAD or chooses finished-hole tolerances. Diagnostic success is separate from candidate fit; unsupported rotations/grid shapes fail explicitly.

integrate_socket_footprints.py consumes the socket module footprint-contract.json and candidate libraries for a guarded native draft correction. It preserves pad identities and all copper except the four declared C352 endpoint changes. Independent checks belong to component-selection/socketing/tools/check_footprints.py. Do not replay over already-adopted boards.

repair_u12_candidate.py writes a new candidate from u12-routing-contract.json; check_u12_routing.py independently checks exact delta, arc tangency, drill preservation and native DRC. audit_copper.py includes wholly unrouted pad nets and explicit branch angles; zero simple bends is never all-corner qualification.

check_copper_coverage.py parses native syntax independently of the pcbnew inventory to verify all pad-connected nets and their reference/pad membership, including wholly unrouted nets. Its receipt is review/copper-coverage-checks.json; current-capacity qualification remains separate.

repair_branch_candidate.py consumes ../branch-routing-contract.json and the exact 738fd04 baseline, producing a fresh temporary candidate only. check_branch_routing.py owns the independent exact-delta, tangent-circle, negative-control, drill and DRC checks. check_u12_routing.verify_current chains this bounded follow-up before the original U12 delta; it does not exempt arbitrary later copper.
# Remaining Power/Control branch correction

`repair_remaining_branches.py` consumes `../remaining-branches-contract.json` and exact baseline boards, using the existing minimal native transform. It refuses an existing candidate directory or altered input. `check_remaining_branches.py` independently validates the declared native delta, arc geometry/tangency, widths, exported holes/slots and native DRC/open-net counts. Its `verify_current` seam lets the socket checker prove the later Control delta before projecting back to its historical socket baseline. Products live in `../review/`; these tools never authorize fabrication. Inspect the native PDF junctions and current holds before adopting a candidate.
