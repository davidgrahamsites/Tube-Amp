Subtitle: "All place external effects BEFORE the spring reverb". EXACT LOGIC for each column:
Column 1 heading: "1  CONSISTENT BUFFERED PATH". Small subheading: "Recommended direction".
Top "Clean / dirty preamp" → "SEND buffer + level reduction".

At this split, left branch "Dry path" directly to "Dry + wet mix"; right branch through "Spring driver" → "Spring tank" → "Recovery + REVERB knob" to the SAME "Dry + wet mix".
Mix → "Tube phase inverter" → "EL34 pair + output transformer" → "Speaker".
Note beneath column: "Same SEND and RETURN stages in both modes. Recalibrate the mix."

Column 2 heading: "2  ORIGINAL BYPASS".

Note: "Original direct path in bypass. Effects mode can change dry / reverb balance."

Column 3 heading: "3  COMPENSATED EFFECTS PATH".
Top "Clean / dirty preamp". SOLID effects route → "SEND buffer + level reduction" → "SEND → pedals → RETURN" → "RETURN gain recovery" → purple box "Loading + gain compensation" → selector "Loop / bypass".

Note: "Compensation must track changing source behavior. Not yet proven."
