# tools
Owner: electric integration.
Inputs: source circuit contract or RENEGADE_LOOP_INPUT snapshot, retained tube and TI OPAx134 models.
Process: fixture.py owns source-derived deck generation; run.py owns bounded AC/transient execution through ../../tools/spice_runtime.py; send_isolation.py screens integrated ideal-branch loading; solver_review.py diagnoses model convergence and compares its optional domain guard; send_driver.py screens the standalone manufacturer SEND model; return_driver.py owns the separate hash-pinned OPA462 RETURN headroom experiment, bounded per case with explicit failures; return_diagnostics.py owns bounded solver-only substitutions without replacing acceptance cases; audit.py checks retained evidence consistency.
Outputs: ../results. Public interfaces: fixture.deck/fingerprint, run.bounded_case/stats and documented command-line factories. No native CAD mutation.
Human check: inspect substitutes, failed/timeout cases and voltage scales before interpreting the aggregate audit. A completed solver case is not a hardware pass.

power_target.py owns the bounded target-drive sweep and separate near-target timestep comparison. audit_power_target.py verifies retained deck/source/result consistency and numerical sensitivity. Their outputs are power-target-* under results; neither selects components nor changes native CAD.

Coupled magnetics and protection: transformer_model.py owns winding substitution; transformer_checks.py independently checks DC rejection, ratio, admittance, energy balance and feedback sign. transformer_run.py owns bounded execution and stress extraction using actual deck resistances. protection_model.py owns explicit resistor/rail/solver deltas; protection_run.py owns the finite comparison/acceptance case matrix. audit_protection.py audits per-case hashes, completion, settling, target refinement and conditional reference-rating limits. Native integration is a separate scoped electrical checkpoint. Source models, circuit coefficients and functional blocks are not silently changed to get convergence.

adopt_protection.py owns the guarded two-resistor native/contract checkpoint; verify_protection_native.py compares its baseline XML/ERC and protected file hashes. Do not rerun adoption over subsequent edits. Factory completion and preserved nets do not establish all-component value parity; the pre-existing D3–D6 discrepancy remains recorded in protection-review.md.

feedback_model.py owns independent magnetizing/leakage/capacitance experiments and explicit compensation overrides. feedback_checks.py measures emitted transformer terminal impedance independently. feedback_sweep.py measures return ratio and validates the closed/open transfer identity. feedback_transient.py owns bounded0.5s amplitude diagnostics; feedback_ringdown.py owns the short HF-resolved burst and timestep negative control. audit_feedback.py verifies provenance and expected failure detection, not that every candidate is acceptable. plot_feedback.py only renders retained numeric evidence. Public result: ../results/feedback-summary.json; interpretation: ../feedback-review.md. No native mutations.

summarize_treble.py compares each compensation candidate to the matched unchanged-C22/R31 baseline at1/5/10/20kHz. It emits feedback-treble-comparison.csv and a hash-pinned summary; no invented user numeric tonal threshold or speaker-response claim.

Loaded-winding seam: loaded_feedback_model.build owns the reciprocal tapped-secondary experiment; loop_probe owns the reusable two-injection AC adapter and independent port cross-check. check_loop_probe.py and check_loaded_winding.py test those seams independently. sweep_loaded_feedback.py owns the finite screening matrix; check_loaded_transient.py owns local burst/timestep controls; audit_loaded_feedback.py checks retained provenance and native preservation; plot_loaded_feedback.py renders numeric evidence only. Public products are ../results/loaded-*. Native adoption is outside these factories.

RETURN causal seam: return_supply_diagnostics.py owns the eight bounded rail/bypass substitutions. return_isolation_check.py owns ten regression cases plus two refinements for the50Ω candidate, through return_driver.measure(case, step_divisor=1, extra_nodes=()). Defaults retain the original measurement behavior. audit_return_supply.py owns retained-deck/source/probe/numerical/native checks and failing controls; no circuit selection occurs here. Read ../return-supply-review.md for the distinction between model completion and actual RETURN acceptance.
