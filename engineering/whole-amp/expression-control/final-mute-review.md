# Final wet-output mute and rail-sequencing diagnostics

2026-11-25, VAL-046. Native engineering repair, not manufacturing release.

The original K3 pole grounds the input to U12. That does not suppress an offset generated by U12 itself during a supply fault. K3's previously unused second pole now grounds WET_AC after C607 when the relay is deenergized. This keeps the dry mixer path and functional blocks intact and adds no component. K3.13 is common/WET_AC, K3.11 is normally closed/GND, K3.9 remains unconnected. The manufacturer bottom-view drawing was visually checked, not inferred from a generic DPDT pinout.

## Native implementation

`tools/integrate_final_mute.py` is a one-time guarded adapter from baseline `df83862dc41f3e43d8d19ec3ee582cc0113abc11`. It changes circuit.json, 07c_reverb_output.kicad_sch and Renegade_Reverb.kicad_pcb only. It does not regenerate the schematic project. Schematic K3C is drawn directly beneath the final wet branch with an explicit remaining-work annotation; the revised PDF and detail were inspected. The note was moved clear of the ground label.

The first route crossed +15V; simply moving it to B.Cu crossed -15V/GND. The retained final route stays on F.Cu until below those horizontal tracks, then uses a 0.8mm via with 0.4mm drill to cross the +15V trace on B.Cu. It uses 0.4mm tracks and 45-degree bends. Five tracks and one via were added; existing tracks, footprint placement, component holes, board outline and mounting holes are preserved.

Fresh KiCad 10.0.6 checks: zero reported reverb-board DRC violations, zero unconnected items, and the existing one GND/PE naming ERC warning unchanged. Native XML changes exactly K3.11 and K3.13; all component identities and other pins remain unchanged. The audit retains ignored DRC categories rather than claiming exhaustive coverage. No populated-fit, all-board current-capacity or fabrication-hole approval follows from this local result.

## Loading and switching limits

`tools/final_mute_loading.py` evaluates 30 passive dry-loading cases: 20Hz–20kHz, dry source resistance 0/10k/100k, and mixer load 1M/10M. U12 is represented as a zero-volt source behind R616=100ohm and C607=1uF. Closing a 0.1ohm contact at WET_AC changes dry magnitude by at most 0.0003151dB and phase by 0.07470 degrees in this fixture. This is not an integrated audio or contact-bounce simulation.

A conservative 16.5V capacitor-step calculation gives 165mA initial current through R616 and 136.1µJ stored energy. Actual op-amp current limiting, contact pulse behavior and resistor pulse rating still need qualification. The relay H1 rating is 1A at 24VDC, not the supplier's generic 2A family description. Low-level contact reliability and audible switching must be bench-tested. Datasheet release timing cannot be used unchanged with the existing flyback diode.

## Rail-sequencing result

`tools/power_sequence.py` runs eight diagnostic UIC cases with ideal supply/reference ramps. Six finish; reference-first and negative-rail-late fail with incomplete solver runs. Those failures are retained. Positive-rail-late and positive-rail-loss produce about 14.49V output excursions in the model; negative-rail-loss ends near 2.5V. None is an acceptable quiet-start result. The OPAx134 model is not qualified below its 5V minimum total operating supply, and rail-loss input common-mode restrictions also matter, so these are design warnings rather than physical fault-voltage predictions.

The relay repair does **not** automatically detect analog rail failure. Existing +5V supervision can leave K3 energized if an analog rail fails. Next: design a socketed, sourceable analog-rail monitor and qualified mute sequencing, including brownout hysteresis, release delay with the actual clamp, and pedal/control input protection. Re-run sequencing with the real supply/monitor circuit before native adoption of that extension. The expression gain cell remains a candidate, not integrated hardware.
