# expression-control contract

Owner: Renegade integration agent. One job: own the protected low-voltage expression-pedal interface.

## Inputs
Paths in this contract are project-root-relative unless named as local. Read `engineering/whole-amp/expression-control/requirements.md` and `engineering/whole-amp/reverb-600/circuit.json`. Local edit/evidence surfaces include `requirements.md`.

## Process
User behavior accepted; exact control circuit and PCB integration pending. Keep source inputs, stable scripts and run products identifiable by their registered roles. This contract adds navigation in place; it does not rerun, relocate or approve the existing design. New active runs belong in a revision module with separate tools, evidence and products.

## Outputs
The local files listed above and their children remain the module outputs. `brain/catalog/FILES.json` indexes their roles and hashes; `brain/materials/register.json` identifies the owning material route.

## Human check
Open the local output with its source/reference and confirm revision, unresolved limits and actual part or circuit identity before using it for the build. For native CAD, inspect the render and pin/geometry checks; for runs, inspect assumptions and logs.
