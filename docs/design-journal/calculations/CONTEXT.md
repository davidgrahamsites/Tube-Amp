# Journal calculation ledger

Owner: Luna journal agent. Canonical executable factories and evidence remain with their engineering module owners; this folder contains readable, source-linked derivations beside narrative choices.

## Inputs
Current engineering source data, manufacturer documents and candidate contracts, source-linked research, and reproducible calculation receipts. Every value needs a named source or an explicit hypothetical assumption.

## Process
For each derivation, state the choice or engineering question it informs; define symbols and units; show the equation and numeric substitution; report units, rounding, checks, assumptions, validation, and scope limits. Keep nominal, tolerance, fault, hypothetical, simulated, and measured values distinct. Do not promote a rating to an operating limit or arithmetic to physical qualification. Link the relevant journal chapter and canonical decision/review.

## Outputs
`current-power-packaging.md` records the present FB-143–148 package, harness, capacitor, and heater calculations; `supply-cutoff.html` records the bounded CB-007 trip, startup, mute, loop and thermal derivations. Add a new ledger only for a bounded evidence checkpoint. The integration owner maintains catalogs; this module does not edit them.

## Human check
Recompute a cited result from its stated inputs and inspect the canonical sources before using it to change a design or claim fit, safety, or build readiness.

Current editable reading copies: current-power-packaging.html and supply-cutoff.html. The power-packaging Markdown file is its prior checkpoint. Use the shared HTML document standard and vocabulary key.
