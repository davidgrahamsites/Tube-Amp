Preamp pass-stage model boundary

November 26, 2026 · HD-006 · Model evidence only

Why the model translation needed checks

The candidate supply uses a floating regulator reference. The TI ATL431A model contains internal ground references that failed our floating fixture and syntax that needs translation for this simulator. The downloaded model file remains unchanged.

The fixture screen used three stages: syntax-only, fixed-clamp translation, and a floating adapter around the model core. It used 18 fixtures: two common-mode offsets and three injected-current levels per stage. The syntax-only and unwrapped grounded-model results were rejected. They do not represent the required floating interface.

The translated model uses local helper syntax for the clamp function. The floating wrapper uses controlled sources to refer the model core to the adapter return. This proves only that the model can be exercised in the proposed reference arrangement. It does not prove hardware behavior.

What the pass-stage screen contains

The screen combines a generic MOSFET LEVEL 1 sensitivity model, a behavioral LM317L model, the adapted ATL431 reference, and a fixed warm-load resistor. The fixed load approximates the nominal earlier supply load. It does not reproduce nonlinear tube current.

Fifty-four DC cases cover three supply inputs, three regulator profiles, warm or unpowered-tube load, and three MOSFET threshold-voltage values. Two fault probes cover an output short and a pass-device short. Four 2 s startup integrations cover 320 V, 380 V, 550 V, and a finer 320 V timestep.

The startup integrations are diagnostics. The ATL431 model excludes loop behavior and temperature. These runs do not establish dynamic stability.

Topology change for this experiment

HD-005 placed 680 Ω in the supply feed. HD-006 instead places 100 Ω in the MOSFET drain feed and 680 Ω in the source path. This is a different experimental topology. Neither arrangement is adopted.

The current model also uses an assumed gate-bias network, local capacitors, a behavioral regulator, and an added load resistor. It omits a gate-voltage protection circuit, reverse-current behavior, thermal shutdown, real semiconductor dynamics, and independent fault interruption.

Pass-short result exceeds model limits

In the pass-short probe at 550 V input, the modeled regulator differential reaches 265.059 V. The LM317L candidate has a 40 V input-to-output absolute maximum. The behavioral model does not enforce that device limit.

\[V_{REG}=V(REGIN)-V(OUT)=538.466-273.407=265.059\;\mathrm{V}\]

The modeled MOSFET gate-to-source voltage reaches −255.086 V. The candidate device has a published ±20 V continuous gate-to-source limit; the surrogate does not enforce it.

\[V_{GS}=V(G)-V(S)=293.435-548.521=-255.086\;\mathrm{V}\]

Both values exceed the devices' model applicability. Treat them as fault probes that expose missing protection. Do not use them as valid device operating predictions or accepted fault performance.

Decision and next checks

HD-006 does not qualify a regulator circuit. The MOSFET is a surrogate, not a validated model of the candidate IXTP3N100D2. The LM317L is behavioral. The reference model has no loop or temperature behavior. No native schematic or board changed. Nothing is adopted.

Before circuit adoption, define and verify gate-voltage protection and current limiting, floating-reference wiring, input-to-output differential protection, reverse-current path, pass-short interruption, thermal design, and exact semiconductor safe operating area. Check socket, carrier, insulation, wiring, and populated fit. Repeat startup and stability work with a supported model or physical measurements.

Vocabulary

Floating reference
A reference node that moves with a local return instead of staying at ground.
Clamp function
A mathematical limit that restricts a value to a stated range.
Controlled source
A modeled source whose output follows a voltage or current elsewhere in the circuit.
Pass device
The transistor that controls current between the supply input and regulated output.
Common-mode offset
A voltage shift applied to related reference nodes together.
Surrogate model
A simplified model used to explore sensitivity. It is not a validated model of the selected part.
Gate-to-source voltage (VGS)
The voltage difference between the transistor gate and source terminals.
Regulator differential
The voltage between the regulator input and output terminals.
Model applicability
The conditions under which a model's equations represent the device closely enough for the intended use.
Safe operating area (SOA)
The voltage, current, and temperature region in which a device can operate without damage.
