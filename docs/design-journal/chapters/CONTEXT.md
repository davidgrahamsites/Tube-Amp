# Journal chapters contract

Owner: Luna journal agent.

## Inputs
Canonical validation/decision records, the owning engineering review and source-bound results, plus parent journal context.

## Process
Write one chronological narrative entry per material issue or grouped checkpoint. Link canonical sources with paths relative to this folder. Separate requirements, evidence, options, decisions, native changes, checks, and physical-build observations. Preserve pending or superseded status accurately.

## Outputs
Stable, source-linked Markdown chapters indexed from `../README.md`.

## Human check
Before public reuse, verify the linked canonical source is current and that the chapter labels simulation, CAD, and physical evidence correctly.
